🏭 Factory Inventory Management System

Full-Stack Architecture Overview

📦 Technology Stack

Frontend

Vue 3 - Composition API for reactive component logic

Vite - Next-gen bundler for fast development

Axios - HTTP client for API communication

Vue Router - Client-side routing

Port: 3000

Backend

FastAPI - Modern Python web framework

Uvicorn - ASGI application server

Pydantic - Data validation & serialization

CORS Middleware - Cross-origin support

Port: 8001

Data Layer

JSON Files - Mock data in server/data/

In-Memory - No database, all filtering in Python

Pydantic Models - Type-safe responses

7 data files

🔄 Data Flow

Vue Component
→
User interacts with UI, applies filters
FilterBar Component
→
Captures: Time Period, Warehouse, Category, Order Status
client/src/api.js
→
Builds query params, makes HTTP GET/POST requests
FastAPI Router
→
Routes request to appropriate endpoint handler
Filter Functions
→
apply_filters() & filter_by_month() - in-memory filtering
Pydantic Models
→
Validates & serializes response data (InventoryItem, Order, etc.)
JSON Response
→
Returned to frontend via HTTP
Computed Properties
→
Vue reactive state updates, components re-render
Key Pattern: Raw data stored in refs (allOrders, inventoryItems), derived data computed on-demand (totalValue, lowStockCount)

🎨 Frontend Structure

Views (Pages)

Dashboard.vue
Summary cards: inventory value, low stock, pending orders, backlog
Inventory.vue
Product catalog, SKU details, warehouse location, reorder points
Orders.vue
Order management, status tracking, delivery dates, customer details
Spending.vue
Financial analytics, monthly trends, category breakdown, transactions
Demand.vue
Demand forecasts, trend analysis, historical vs. predicted demand
Reports.vue
Quarterly performance, fulfillment rates, revenue trends

Key Components

FilterBar.vue
Global filter system - applies to all data views. Captures: Time Period (Q1-Q4 or month), Warehouse, Category, Order Status
Modal Components
ProductDetailModal, InventoryDetailModal, BacklogDetailModal, CostDetailModal - detailed views with drill-down functionality
Composables
useFilters.js (filter state), useAuth.js (user context), useI18n.js (i18n support)

📡 API Endpoints

Inventory Management

GET /api/inventory?warehouse=X&category=Y
Response: InventoryItem[] - SKU, quantity, cost, location
GET /api/inventory/{item_id}
Get single inventory item details

Order Management

GET /api/orders?warehouse=X&status=Y&month=Z
Response: Order[] - customer, items, status, dates, value
GET /api/orders/{order_id}
Get order details with line items

Analytics & Forecasting

GET /api/demand
Demand forecasts with trend indicators
GET /api/backlog
Delayed orders, priority levels, purchase order status
GET /api/dashboard/summary?warehouse=X&month=Y
KPIs: inventory value, low stock count, pending orders

Financial Data

GET /api/spending/summary
Total spending, YTD totals, budget status
GET /api/spending/monthly
Monthly spending breakdown
GET /api/spending/categories
Spending by product category
GET /api/spending/transactions
Recent transaction history

Reports

GET /api/reports/quarterly
Q1-Q4 performance: revenue, fulfillment rate, order count
GET /api/reports/monthly-trends
Month-over-month trends in orders, revenue, delivery

📂 Data Sources

inventory.json

Product catalog with SKU, warehouse location, quantity on hand, reorder point, unit cost

orders.json

Customer orders: order number, customer name, items, status (Processing/Backordered/Delivered), dates, total value

demand_forecasts.json

Predicted demand: current vs. forecasted, trend indicator, period

backlog_items.json

Delayed/unfulfilled orders: quantity needed, available, days delayed, priority level

spending.json

Financial summary: monthly breakdown, category allocation, budget goals ($800K/month, $9.6M YTD)

transactions.json

Recent activity log: purchases, payments, refunds, adjustments with amounts and dates

purchase_orders.json

Supplier orders: linked to backlog items, quantity, unit cost, expected delivery, status

✨ Key Features & Patterns

Filter System

Time Period
Q1-Q4 2025 or individual months for granular date filtering
Warehouse
Filter by physical location/warehouse code
Category
Product category filtering (Materials, Components, etc.)
Order Status
Processing, Backordered, Delivered status filters

Reactivity Pattern

Raw Data (refs)
allOrders, inventoryItems - unfiltered data loaded from API once
Computed Properties
totalInventoryValue, lowStockCount, pendingOrders - derived from raw data, auto-update when source changes

Important Constraints

No Database
All data in JSON files, loaded at startup, filtered in-memory
Inventory Filters
No time dimension - inventory represents current state only
v-for Keys
Must use unique identifiers (sku, id), never index
Revenue Goals
$800K/month single warehouse, $9.6M YTD all warehouses
