Factory Inventory Management System

Full-Stack Architecture Overview

System Overview

A full-stack inventory management system for factory operations, featuring real-time inventory tracking, order management, demand forecasting, and spending analysis. Built with modern web technologies and in-memory mock data for rapid prototyping.

⚡ Key Characteristics:
• In-memory data (no database) for fast development
• RESTful API with automatic OpenAPI documentation
• Real-time filters applied across all views
• Modular component architecture
• CORS-enabled for cross-origin requests

Filter System

Four primary filters apply across most API endpoints to enable flexible data queries:

⏰ Time Period
Q1-2025, Q2-2025, Q3-2025, Q4-2025, or specific month (2025-01)
🏭 Warehouse
Filter inventory and orders by physical warehouse location
📂 Category
Electronics, Raw Materials, Finished Goods, Components
🔄 Order Status
Pending, In Transit, Delivered, Cancelled

Frontend Views

Dashboard

Overview of key metrics, KPIs, and system health. Displays total inventory value, order statistics, and performance indicators with all filters applied.

Inventory

Browse all inventory items with SKU, quantity on hand, reorder points, costs, and warehouse locations. Filter by warehouse and category.

Orders

Manage customer orders including order number, customer name, items, status, and expected delivery dates. Supports all filters.

Demand

View demand forecasts showing current vs. forecasted demand with trend analysis for upcoming periods.

Backlog

Monitor delayed items and backorders with quantity discrepancies and days delayed information.

Spending

Analyze spending patterns across time periods, categories, and transactions with monthly trends and forecasts.

Key Features

🔄 Real-Time Filtering

Apply filters across multiple dimensions (time, location, category, status) to get instant, focused data views. Changes propagate immediately to all connected components.

📡 REST API

Clean RESTful API endpoints with automatic OpenAPI/Swagger documentation. Query parameters control filtering. Pydantic models ensure type-safe responses.

⚡ Fast Development

In-memory mock data eliminates database setup. Changes to JSON files reload on server restart. Perfect for rapid prototyping and iteration.

🎯 Responsive UI

Vue 3 Composition API with computed properties for derived data. Reactive state management ensures UI updates automatically when filters change.

📊 Analytics Ready

Comprehensive spending analysis, demand forecasting, and backlog tracking. Pre-computed summary data for fast dashboard loads.

🔗 CORS Enabled

Cross-origin requests allowed for development. Frontend and backend run on different ports (3000 and 8001) without browser restrictions.

Running the System

▶️ Start Backend

From the server directory:

uv run python main.py

Runs on http://localhost:8001
API Docs: http://localhost:8001/docs

▶️ Start Frontend

From the client directory:

npm install && npm run dev

Runs on http://localhost:3000
