Factory Inventory Management System

A demo full-stack application: a Vue 3 single-page dashboard backed by a FastAPI service that serves in-memory mock data loaded from JSON files. There is no database.

System architecture

Three tiers, run locally as two processes.

Frontend

Vue 3 + Vite · localhost:3000
  • 6 routed views: Dashboard, Inventory, Orders, Demand, Spending, Reports
  • Shared filter state (useFilters)
  • English / Japanese UI (useI18n)
  • Detail modals, custom SVG charts
  • Axios client in api.js

  • REST endpoints under /api
  • Shared filter helpers: apply_filters, filter_by_month

Data flow

How a filter change on screen becomes updated data.

  1. User changes a filterTime period, warehouse, category, or order status in the filter bar updates shared refs in useFilters.
  2. View requests datagetCurrentFilters() builds a filter object; api.js drops any value set to all and sends the rest as query parameters.
  3. FastAPI filters in memoryThe endpoint calls apply_filters (warehouse, category, status) and filter_by_month (month or quarter, matched against order_date).
  4. Pydantic validates the responseResults are serialised through the response model, e.g. InventoryItem or Order.
  5. Vue rendersThe view stores raw results in refs (allOrders, inventoryItems); charts, totals and tables are computed properties derived from them.
