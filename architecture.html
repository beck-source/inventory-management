Request / Data Flow

1

Filter selection

User adjusts one of four filters (Time Period, Warehouse, Category, Order Status) via FilterBar.vue, backed by the useFilters composable.

2

API request

A view (Dashboard.vue, Inventory.vue, etc.) calls a function in client/src/api.js, which builds query params and issues a GET/POST via axios to http://localhost:8001/api/*.

3

FastAPI routing

server/main.py receives the request and validates any body/response against Pydantic models (InventoryItem, Order, etc.).

4

In-memory filtering

Data loaded once at startup by mock_data.py from server/data/*.json is filtered in plain Python (apply_filters, filter_by_month) — no database round-trip.

5

Response → reactive state

JSON comes back, is stored in raw refs (allOrders, inventoryItems), and Vue computed properties derive the totals/charts rendered on screen.
