Factory Inventory Management System

Full-stack demo app: a Vue 3 single-page frontend talking to a read-only FastAPI service backed by JSON files loaded into memory at startup. No database, no authentication, no persistence.

Vue 3.4 + Vite 5.2 FastAPI 0.110 + Pydantic 2.5 Python ≥3.11 / uv :3000 → :8001 ~8,500 LOC client

Data Flow — A Filter Change, End to End

  1. User picks a filter in FilterBar.vue, rendered once in App.vue above <router-view>, so it persists across navigation.
  2. FilterBar writes to shared refs. useFilters.js declares selectedPeriod, selectedLocation, selectedCategory, selectedStatus at module scope — a singleton. Every importer sees the same four refs.
  3. Views react and call getCurrentFilters(), which maps UI names to API names: selectedLocation → warehouse, selectedPeriod → month.
  4. The view calls api.js — the one module that knows the backend URL.
  5. api.js drops 'all' values, builds URLSearchParams, and issues axios.get to http://localhost:8001/api. Absent param means unfiltered.
  6. FastAPI binds query params as Optional[str], defaulting to None.
  7. Filtering runs in Python. apply_filters() chains warehouse (exact), category and status (both case-insensitive). filter_by_month() then does a substring match on order_date, or expands a quarter through QUARTER_MAP.
  8. Pydantic validates the response against response_model. A JSON field that drifts from the model raises here, not at the client.
  9. JSON crosses back over CORS (allow_origins=["*"]).
  10. The view stores raw data in refs, then derives every KPI, table row and SVG chart series in computed properties — cached until the refs change.

Notable Findings

Reports.vue departs from every project convention planted

The only view built on the Options API (data()/mounted()/methods) rather than setup(). It is also the only view that imports axios directly with a hardcoded http://localhost:8001 instead of going through api.js, the only one that skips useFilters (so the global FilterBar silently does nothing on this page), the only one that skips useI18n (so its strings never translate), and it carries 13 console.log calls. This is the Expert Challenge target.

Backlog.vue is unreachable dead code

152 lines, correctly wired to useFilters — and never imported by anything. It has no entry in the main.js router and no nav link, yet the README advertises "Backlog monitoring" as a feature and /api/backlog serves it. Like Reports, it also skips useI18n. Reaching it requires adding the route first.

Six api.js methods call routes that do not exist contract gap

getTasks, createTask, deleteTask, toggleTask, createPurchaseOrder and getPurchaseOrderByBacklogItem target /api/tasks and /api/purchase-orders. Neither path is defined in main.py — all six 404. App.vue swallows the tasks failure in a catch and falls back to the mock tasks in useAuth.js, so the UI looks fine while the network tab fills with errors.

Hardcoded "Reports" nav label i18n

App.vue:26 renders the literal string Reports while its five siblings all use t('nav.*'). The tab stays English when the app switches to Japanese.

total_backlog_items ignores the filters correctness

In /api/dashboard/summary, every other figure is computed from filtered data, but total_backlog_items is len(backlog_items) — the unfiltered global. Narrow the dashboard to one warehouse and that one card keeps showing the company-wide count.

Unknown quarters silently return everything correctness

filter_by_month() checks month.startswith('Q'), then looks the value up in QUARTER_MAP. On a miss, control falls through to the trailing return items — unfiltered, no error. QUARTER_MAP is also hardcoded to 2025, so the same silent pass-through hits every other year.

CORS wildcard combined with credentials config

allow_origins=["*"] with allow_credentials=True is a combination the fetch spec rejects — browsers refuse credentialed wildcard responses. Harmless here because nothing sends credentials, and the repo is explicit that it is local-demo only.

Inventory has no time dimension by design

/api/inventory accepts only warehouse and category. The Time Period filter is silently dropped for inventory data — documented as known in the root CLAUDE.md, not a bug.
