Catalyst Components — Factory Inventory Management

System Architecture

A full-stack demo: a Vue 3 single-page app talks over HTTP/JSON to a Python FastAPI service that serves filtered views of in-memory mock data. No database — all data is loaded from JSON files at startup.

Vue 3 + Vite FastAPI Python Axios / REST In-memory data i18n: EN / JA

Data Flow — The Filter Pipeline

Four shared filters — Time Period, Location, Category, Order Status — drive every data view through one reactive pipeline.

FilterBar.vue binds four <select> elements via v-model directly to refs exported by useFilters.js.
Because useFilters declares its refs at module scope, every view shares the same reactive state — a singleton store.
Each view runs watch([...filters], loadData), so changing any dropdown triggers a reload automatically.
getCurrentFilters() builds a params object { warehouse, category, status, month? } — omitting any value left at 'all'.
api.js turns params into URLSearchParams and issues an Axios GET to FastAPI.
FastAPI runs apply_filters() then filter_by_month() over the in-memory arrays and returns Pydantic-validated JSON.
The view stores raw results in refs; computed properties derive KPIs, charts, and sorted tables for render.

Frontend Structure

Views (routed)
  • Dashboard / — KPIs, order-health donut, category bars, shortages, top products
  • Inventory /inventory — stock table, text search, status sort
  • Orders /orders — status cards + expandable orders table
  • Demand /demand — trend cards + forecast table
  • Spending /spending — financial KPIs, cost-flow charts
  • Reports /reports — quarterly & monthly analysis (Options API)

Backlog.vue exists but has no route — dead code; its data surfaces inside Dashboard.

Composables (singletons)
  • useFilters — the 4 shared filter refs, resetFilters(), getCurrentFilters()
  • useI18n — t() lookup, EN/JA locale, localStorage persistence, currency coupling
  • useAuth — mock user, language-aware profile, tasks
Components
  • FilterBar — the 4 filter dropdowns
  • 5 detail modals — Inventory, Backlog, Product, Cost, Profile
  • ProfileMenu, TasksModal, LanguageSwitcher
Utilities
  • currency.js — formatCurrency() etc.; USD↔JPY at a fixed 150x rate, coupled to locale
