Factory Inventory Management System

A full-stack demo app for factory operations: inventory, orders, demand forecasting, spending and reports. It's a Vue single-page app talking to a stateless FastAPI service that serves JSON data held in memory.

Data Flow

Example: a user changes the Warehouse filter on the Dashboard.

FilterBar

Writes to shared refs in useFilters. They're module-level singletons, so every view sees the same state.

View watcher

Dashboard watch()es the 4 filter refs and calls getCurrentFilters().

api.js

Builds query params and drops any filter set to 'all'. Calls run in parallel via Promise.all.

FastAPI

apply_filters() then filter_by_month() run over in-memory lists. Quarters map to 3 months.

Pydantic

The response model checks the shape and FastAPI serialises it to JSON.

Computed

Raw data lands in refs. KPIs, charts and tables are computed from it, and currency is formatted per locale.

Things to Know

Found while reading the code and checking it against the running server.

The frontend calls endpoints the backend doesn't have

api.js defines task CRUD (/api/tasks) and purchase-order calls (/api/purchase-orders), but neither route exists in main.py, so both return 404 on the live server.

The Backlog view isn't reachable

views/Backlog.vue exists and fetches data, but it isn't registered in main.js and the nav has no link to it. Backlog data only shows up on the Dashboard.

Backlog totals ignore filters

total_backlog_items in the dashboard summary always counts every backlog item, even when other filters are active.

Hard-coded values

The API base URL (localhost:8001) is in api.js and again in Reports.vue. Quarters only cover 2025 (QUARTER_MAP), and the JPY exchange rate is fixed at 150.

Auth is mocked

useAuth returns a fixed user with isAuthenticated = true. There's no auth on the backend, and CORS allows any origin.
