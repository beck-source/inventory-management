System Architecture

Factory Inventory Management System

A full-stack demo application for factory operations — inventory tracking, order management, demand forecasting, backlog monitoring, and spending analytics. Vue 3 single-page app backed by a FastAPI service reading from static in-memory JSON data (no database).

Request Data Flow

1
Filter selection
User picks Time Period, Warehouse, Category, or Order Status in FilterBar.vue, backed by the useFilters.js composable.
→
2
api.js call
The active view (e.g. Dashboard.vue) calls a method on api.js, which builds query params and issues an Axios GET.
→
3
FastAPI route
main.py matches the endpoint, applies apply_filters()/filter_by_month() over the in-memory lists.
→
4
Pydantic validation
Filtered results are validated/serialized against response models and returned as JSON.
→
5
Reactive render
Response is stored in a ref (e.g. allOrders); computed properties derive display data and the template re-renders.
