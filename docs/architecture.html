Factory Inventory Management System

A full-stack demo: a Vue 3 single-page app talking to a FastAPI backend, serving in-memory data loaded from JSON. Runs locally with no database and no authentication.

There is no database and no write path for the core data. The frontend only reads, and the backend keeps everything in memory for the life of the process.

Data flow

Example: the user picks Warehouse = Tokyo and Period = April 2025, and the Orders page reloads.

  1. User changes a filterFilterBar.vue updates the shared refs in composables/useFilters.js
  2. View requests dataOrders.vue calls getCurrentFilters(), then api.getOrders(filters)
  3. API client builds the URLapi.js drops all values and sends GET /api/orders?warehouse=Tokyo&month=2025-04
  4. FastAPI routes the requestmain.py validates query params and calls apply_filters(), then filter_by_month()
  5. Backend filters in memoryMatching is a substring test of 2025-04 against order_date. The API also accepts quarters like Q2-2025 via QUARTER_MAP, but the UI only offers months
  6. Response is validatedThe result passes through the Order Pydantic model, then serializes to JSON
  7. Vue rendersRaw data goes into refs; charts and KPIs are derived in computed properties

Known gaps

These were found by checking the code against the running backend. They don't stop the app from starting.

ItemStatusDetail
/api/tasks (GET, POST, PATCH, DELETE) Missing The client calls these from App.vue, but main.py has no such routes and they return 404. The tasks panel shows only the mock tasks from useAuth.js.
/api/purchase-orders Missing api.js defines create and lookup calls, but no backend route exists and no view calls them. purchase_orders.json is empty.
Backlog page Unrouted views/Backlog.vue exists but is not registered in main.js or the nav bar. Backlog data still appears on the Dashboard.
CORS Open The backend allows all origins with credentials. This is fine for a local demo and not suitable for deployment.
Hardcoded API URL Local only api.js and Reports.vue point to http://localhost:8001. Deployment would need an env variable.
