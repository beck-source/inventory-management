Factory Inventory Management System

Architecture overview — a full-stack demo application for inventory, order, and spending management across factory warehouses. Vue 3 frontend, Python FastAPI backend, in-memory JSON data (no database).

Data Flow — Example: Filtering Inventory by Warehouse

  1. User changes a filter
    The Location dropdown in FilterBar.vue is v-model-bound to selectedLocation, a ref exported by the useFilters() composable — a module-level singleton shared by every component that imports it.
  2. A watcher fires
    Inventory.vue also calls useFilters() and has watch([selectedLocation, selectedCategory], loadInventory), so the change triggers a reload.
  3. Frontend calls the API client
    loadInventory() reads getCurrentFilters() and calls api.getInventory({ warehouse, category }) in client/src/api.js, which builds a URLSearchParams and issues axios.get.
  4. FastAPI routes the request
    GET /api/inventory is handled by get_inventory(warehouse, category) in server/main.py.
  5. In-memory filtering
    apply_filters(inventory_items, warehouse, category) filters the list already loaded into memory by mock_data.py from inventory.json.
  6. Validation & response
    FastAPI serializes the result against response_model=List[InventoryItem] (a Pydantic model) and returns JSON.
  7. Computed properties re-derive UI state
    The response fills a ref; a computed() layers on client-side search and stock-status sorting before the table re-renders with v-for="item in filteredItems" :key="item.id".

Known Gaps

Tasks & Purchase Orders — frontend/backend mismatch
client/src/api.js calls /api/tasks and /api/purchase-orders, but no such routes exist in server/main.py. These calls fail silently (caught, logged) and the UI falls back to local mock state from useAuth.js.
Backlog view is unreachable
Backlog.vue exists but isn't registered in client/src/main.js's router — there's no nav path to it.
Test docs are stale
tests/README.md references a test_orders.py that doesn't exist; only 3 test files are actually present (inventory, dashboard, misc endpoints).
