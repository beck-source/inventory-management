🏭 Factory Inventory Management System

System Architecture & Technical Overview

System Overview

A full-stack inventory management and analytics platform for factory operations. Tracks inventory across multiple warehouses, manages orders with demand forecasting, and provides real-time spending analytics.

📦 Inventory Tracking

Real-time monitoring of stock levels across warehouses with SKU-based categorization and reorder point management

📋 Order Management

Complete order lifecycle tracking with status management (Delivered, Shipped, Processing, Backordered)

🔮 Demand Forecasting

Predictive analytics for inventory demand with trend analysis (increasing, stable, decreasing)

💰 Spending Analytics

Cost tracking by category with monthly breakdowns and transaction-level details

System Architecture

🖥️ Presentation Layer (Port 3000)
Vue 3 Components → Dashboard, Inventory, Orders, Spending, Demand Forecasts, Reports
🔗 API Client Layer
Axios HTTP Client → Query Parameter Building → Filter State Management
⚙️ Application Layer (Port 8001)
FastAPI Endpoints → Request Validation → Business Logic → Response Formatting
🔍 Data Processing Layer
Filter Functions → In-Memory Data Processing → Pydantic Model Serialization
💾 Data Layer
JSON Files (inventory.json, orders.json, demand_forecasts.json, etc.) → Loaded at Startup

Request/Response Data Flow

Example: User applies filters and loads inventory

User Action Selects warehouse filter in UI
Vue Component Updates useFilters() composable reactive state
API Client Calls api.getInventory({ warehouse: 'West' })
HTTP Request GET /api/inventory?warehouse=West sent to backend
FastAPI Route handler validates query params with Pydantic
Filtering apply_filters() processes in-memory inventory data
Response Serializes filtered items as JSON list
Vue Component Stores data in ref(), computed properties render UI

Core API Endpoints

Inventory

GET /api/inventory Filters: warehouse, category | Returns: List of inventory items with quantities and costs

Orders

GET /api/orders Filters: warehouse, category, status, month | Returns: Complete order data with item details

Dashboard

GET /api/dashboard/summary Filters: warehouse, category, status, month | Returns: KPI metrics (pending orders, low stock, inventory value)

Analytics

GET /api/demand No filters | Returns: Demand forecasts with trends
GET /api/backlog No filters | Returns: Backlog items with priority and delay data
GET /api/spending/summary No filters | Returns: Spending by cost category

Key Features & Patterns

✅ What's Implemented

  • Unified Filter System — 4 core filters (warehouse, category, status, month) applied consistently across all endpoints
  • Multi-Language Support — i18n composable for English/Chinese/other languages
  • In-Memory Mock Data — 7 JSON files loaded at startup, suitable for demo/testing
  • Custom SVG Charts — No charting library; responsive SVG with CSS Grid layouts
  • Client-Side State Management — Composables + refs (no Vuex/Pinia for simplicity)
  • Comprehensive Test Coverage — 55 pytest tests covering all API endpoints
  • Full CORS Support — Wildcard CORS for development convenience

🔄 Data Flow Principles

  • Filters → Query params → Backend processing → Pydantic validation → JSON response
  • Raw data in Vue refs, computed properties for derived/transformed data
  • All filtering logic on server side (single source of truth)
  • Unique keys for v-for loops (never index)

Development Workflow

Running Locally

# Terminal 1 - Backend
cd server
python -m pip install -r requirements.txt
python main.py # http://localhost:8001

# Terminal 2 - Frontend
cd client
npm install
npm run dev # http://localhost:3000

Running Tests

cd tests
python -m pytest backend/ -v # Run all 55 tests
python -m pytest backend/test_inventory.py -v # Single file

Adding Features

  1. New View: Create .vue in client/src/views/ → Add route in main.js → Add nav link in App.vue
  2. New Endpoint: Define Pydantic model → Create handler in server/main.py → Write tests in tests/backend/
  3. New Component: Create .vue in client/src/components/ → Import & use in views
