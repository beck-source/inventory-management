Notes

No database

All data lives in JSON files under server/data/, loaded into memory once on server start. Writes (tasks, purchase orders) only persist for the life of the process.

Shared filter system

Four filters — Time Period, Warehouse, Category, Order Status — flow through query params to nearly every endpoint, keeping views consistent.

Reactivity pattern

Raw API responses are stored in refs; anything derived (totals, chart series, filtered lists) is a computed property, recalculated only when its dependencies change.

Demo, not production

No authentication, no database, CORS wide open, no rate limiting — intentionally scoped for a workshop demo, not deployment.
