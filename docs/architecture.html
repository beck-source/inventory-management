Inventory Management System — Architecture Overview

A full-stack demo application for factory inventory, orders, demand, and spending tracking. Vue 3 single-page frontend, FastAPI backend, no database — all data is served from in-memory Python structures loaded from static JSON files.

Data Flow — Worked Example (Dashboard Summary)

  1. User adjusts a filter
    Selecting a warehouse, category, status, or time period in FilterBar.vue updates the shared singleton refs in useFilters.js.
  2. View reads current filters
    The active view (e.g. Dashboard.vue) reads getCurrentFilters() and calls api.getDashboardSummary(filters).
  3. Request built
    api.js builds a URLSearchParams (omitting any filter set to 'all') and issues GET /api/dashboard/summary?warehouse=...&category=...&status=...&month=....
  4. FastAPI handles the request
    get_dashboard_summary() in main.py receives the query params, applies apply_filters() and filter_by_month() against the in-memory inventory_items and orders lists.
  5. Response returned
    Aggregates (inventory value, low-stock count, pending orders, backlog count, orders value) are computed and returned as JSON.
  6. Vue updates reactively
    Axios resolves the response into a ref; computed properties derive formatted, display-ready values and the template re-renders.
