Key Components

Views (client/src/views/)

  • Dashboard — KPIs, revenue, charts
  • Inventory — items, warehouse/category filters
  • Orders — order list, status filters
  • Demand — forecast trends
  • Spending — summary, monthly, transactions
  • Reports — quarterly & monthly trends
  • Backlog — shortages, PO creation flow

Shared State (composables)

  • useFilters — global period/warehouse/category/status refs
  • useAuth — mock current user, session state
  • useI18n — locale (en/ja), currency formatting
  • No Vuex/Pinia — module-scope singleton refs
  • Raw data in refs, derived data in computed()

Notes

Gaps found during investigation

  • api.js calls /api/tasks* and POST /api/purchase-orders, but these routes don't exist in main.py — these calls 404 against the live backend today.
  • Reports.vue appears to call /api/reports/* directly rather than through api.js, inconsistent with the centralized-client pattern used elsewhere.
  • No Vite dev-server proxy — the frontend calls http://localhost:8001/api directly (hardcoded), relying on open backend CORS (allow_origins=["*"]) rather than a proxy.
  • tests/backend/ has no test_orders.py, despite one being referenced in tests/README.md/TEST_SUMMARY.md.
