Factory Inventory Management System

A demo full-stack application: a Vue 3 single-page dashboard served by Vite, a FastAPI REST backend, and in-memory data loaded from JSON files. There is no database.

Data flow

  1. User changes a filter.
    Time period, warehouse, category and order status live in useFilters.js as shared singleton refs.
  2. View requests data.
    getCurrentFilters() builds a filter object; client/src/api.js turns it into query params, skipping values set to "all".
  3. FastAPI handles the request.
    The endpoint filters the in-memory lists (warehouse, category, status, month) and aggregates where needed.
  4. Response is validated.
    Pydantic response_model shapes the JSON; the backlog endpoint also adds a has_purchase_order flag by joining against purchase orders.
  5. Frontend renders.
    Raw data is stored in refs (for example allOrders, inventoryItems); charts, totals and tables are computed properties derived from them.

Data model

Inventory

SKU, category, warehouse, quantity on hand, reorder point, unit cost, location.

Orders

Customer, line items, status, order and delivery dates, total value, warehouse, category.

Demand forecasts

Current versus forecasted demand per SKU, with trend and period.

Backlog items

Quantity needed versus available, days delayed, priority. Linked to orders.

Purchase orders

Supplier, quantity, unit cost and expected delivery, linked to a backlog item.

Spending and transactions

Summary, monthly and category spending, plus recent transactions.

  • Frontend: cd client && npm install && npm run dev
