Tech Stack

Frontend

Vue 3 Composition API SPA built with Vite. Module-singleton composables replace a store library. Custom SVG charts — no external chart dependency.

vue 3.4 vite 5 vue-router 4 axios 1.6

Backend

Python FastAPI with Pydantic v2 models. All filtering via in-memory Python list comprehensions. No ORM, no database connection. uv for package management.

fastapi 0.110+ pydantic v2 uvicorn uv

Data & i18n

Static JSON files loaded once at startup. No persistence between restarts. Two locales (EN/JA) via a custom key-lookup composable. USD→JPY at a hardcoded rate of 150.

JSON (7 files) EN / JA in-memory

Filter Data Flow

1

FilterBar.vue

4 <select> dropdowns bound via v-model to module-singleton refs in useFilters.js.

2

Reactive Watchers

Each view watch()es all 4 filter refs. Any change fires loadData().

3

api.js

Builds URLSearchParams. Values of 'all' are omitted. Sends axios.get().

4

FastAPI

apply_filters() + filter_by_month() run list comprehensions on in-memory arrays.

5

Computed Props

Views derive cross-entity data (e.g. topProducts) from filtered refs via computed().

Filter scope notes:  Inventory does not support month or status (no time dimension on stock).  Demand and Backlog accept no query params — filtered client-side by SKU cross-reference.  Spending summary recalculates from a client-side slice; monthly chart always shows all 12 months.

Key Patterns

Module-Singleton Composables

Filter state (useFilters), locale (useI18n), and auth (useAuth) are declared as module-level refs outside the exported function. ES module caching makes every caller share the same reactive instance — no Pinia or Vuex needed.

In-Memory Filtering

All server-side filtering is Python list comprehensions in apply_filters() and filter_by_month(). Quarter names like Q1-2025 are expanded via a QUARTER_MAP dict into month ranges before substring-matching on order_date.

Custom SVG Charts

All charts (donut, horizontal bar, stacked bar, vertical bar) are hand-coded SVG with no external library. This keeps the bundle small but means chart logic lives inline in each view file.

i18n Without a Library

useI18n.js implements dot-path key lookup against locales/en.js and locales/ja.js with English fallback. Currency conversion is locale-driven: EN → USD, JA → JPY (rate: 150, hardcoded in utils/currency.js).

Raw Refs + Computed Derivation

Views store raw API data in refs (allOrders, inventoryItems) and derive cross-entity values (top products, low-stock counts) in computed properties. This avoids redundant API calls when display logic changes.

Teleport + Transition Modals

All 5 detail modals use <Teleport to="body"> to escape stacking contexts, wrapped in a Vue <Transition> for slide-in animation. Modal state is managed as props/emits rather than global state.
