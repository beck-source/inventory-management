Factory Inventory Management System

Architecture overview: a Vue 3 single-page app talks to a FastAPI service over JSON. The service serves in-memory data loaded from JSON files at startup. There is no database.

Data Flow

Filter change

The user changes time period, warehouse, category, or order status in FilterBar. The state lives in useFilters.

View reacts

A view watches the filter refs and calls the matching method in src/api.js. Empty filter values ("all") are dropped from the query string.

HTTP request

Axios sends GET http://localhost:8001/api/... with query params. CORS allows the request.

Server filtering

apply_filters and filter_by_month run over the in-memory lists. Quarters map to month strings (for example, Q1-2025 to 2025-01 through 2025-03).

Validation

Results are shaped by Pydantic response_models, so the JSON matches the declared fields.

Render

The view stores raw data in refs, derives values with computed, and re-renders charts and tables.

Known Gaps

Task and purchase-order endpoints are missing. api.js and App.vue call /api/tasks and /api/purchase-orders, but server/main.py does not define them. Those requests return 404. CreatePurchaseOrderRequest is defined but unused.
Reports endpoints have no caller. The client's /reports view does not request /api/reports/*.
Backlog view is unrouted. views/Backlog.vue exists, but main.js defines no /backlog route.
Security is demo-only. There is no authentication, CORS allows all origins, and the user is mocked on the client. Writes are not persisted.
