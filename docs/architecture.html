System Documentation

Factory Inventory Management System

A full-stack demo application: Vue 3 + Vite frontend, FastAPI backend, and in-memory JSON mock data. This page summarizes the architecture, tech stack, data flow, and public API surface.

Tech Stack

Three thin layers — presentation, HTTP API, and JSON-backed data — with no database.

Frontend
Vue 3 · Vite
Port 3000 · Composition API
  • vue 3.4 · vue-router 4
  • axios HTTP client
  • Vite 8 dev server & build
  • Custom SVG charts (no chart library)
Backend
FastAPI · Uvicorn
Port 8001 · Python 3
  • FastAPI route handlers
  • Pydantic models for validation
  • Permissive CORS (dev only)
  • Run via uv run python main.py
Data
In-memory JSON
server/data/*.json
  • Loaded at startup by mock_data.py
  • 7 JSON files (inventory, orders, …)
  • Filtered in Python per request
  • Mutations don't persist across restarts
Tooling
uv · npm · pytest
Dev & test workflow
  • uv for Python deps & runs
  • npm run dev for Vite
  • pytest + FastAPI TestClient
  • Playwright for UI testing

System Architecture

A single request path: the browser renders Vue views, which call api.js, which hits FastAPI, which filters the in-memory JSON data and returns Pydantic-validated responses.
