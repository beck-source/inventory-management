Request & Data Flow

1
User adjusts a filter
Time Period, Warehouse, Category, or Order Status changes in FilterBar.vue, updating shared state in the useFilters composable.
2
View calls the API client
A view (e.g. Dashboard.vue) calls a function in client/src/api.js, which builds query params and sends a request via Axios.
3
FastAPI receives the request
A route in server/main.py parses optional query params (warehouse, category, status, month).
4
In-memory filtering
apply_filters() and filter_by_month() run against the in-memory lists loaded from JSON — no database query.
5
Pydantic validates the response
Filtered results are coerced into typed models (InventoryItem, Order, etc.) before being serialized to JSON.
6
Vue renders derived state
Raw response data lands in a ref(); computed properties derive chart data, KPIs, and totals, and the template re-renders reactively.

Frontend Structure

Views — client/src/views/

  • Dashboard.vue — KPIs, order health, category value
  • Inventory.vue — stock levels by warehouse
  • Orders.vue — order tracking & status
  • Demand.vue — forecasting & trends
  • Backlog.vue — delayed / at-risk items
  • Spending.vue — cost analytics
  • Reports.vue — quarterly / monthly trends

Components & Composables

  • FilterBar.vue — shared filter controls
  • *DetailModal.vue — Inventory, Product, Cost, Backlog, Profile
  • useFilters.js — shared filter state
  • useAuth.js — auth/user state
  • useI18n.js — locale switching (en / ja)
  • currency.js — number/currency formatting
