Factory Inventory Management System

Architecture overview of a full-stack demo app for factory operations: inventory tracking, order management, demand forecasting, spending analytics and reports. It is a single-page Vue client that talks to a stateless FastAPI service serving in-memory JSON data.

Vue 3 · Vite FastAPI · Pydantic v2 In-memory JSON (no database) i18n: EN / JA pytest · 40 backend tests

System architecture

Three tiers on one machine. The browser loads the SPA from Vite and calls the API directly over CORS. There is no proxy, no auth and no persistence layer.

Data flow

Every view follows the same request/response cycle. Filters are global, so changing one in the top bar re-queries whichever view is on screen.

FrontendUser changes filter

FilterBar writes to shared refs in useFilters (period, location, category, status).

FrontendView reacts

A watch() on the filter refs calls loadData() and reads getCurrentFilters().

Frontendapi.js builds query

Drops 'all' values, maps location to warehouse and period to month, then sends an axios GET.

BackendFilter in Python

apply_filters() and filter_by_month() run list comprehensions over in-memory data.

BackendValidate & return

response_model validates against Pydantic models and serialises JSON.

FrontendRender

Raw data goes into refs. computed() derives KPIs and chart series, formatted per locale and currency.

Findings & constraints

Things I noticed while reading the code that are worth knowing before you change it.

Missing backend endpointsThe client calls /api/tasks (GET/POST/PATCH/DELETE) and /api/purchase-orders, but main.py has no route for either, so those calls return 404. The PurchaseOrder and CreatePurchaseOrderRequest models exist but nothing uses them.
Unrouted viewviews/Backlog.vue exists and calls the API, but main.js has no /backlog route. Backlog data only appears on the Dashboard.
Inconsistent API accessReports.vue imports axios directly with hard-coded URLs instead of going through api.js. The base URL is also hard-coded rather than set from an env variable.
Data is read-only and volatileData loads once at import. Edits to data/*.json need a server restart, and any future write endpoints would lose their changes on restart.
Time handling is 2025-onlyQUARTER_MAP and the quarterly report hard-code 2025. Month filtering uses substring matching on order_date, and inventory has no time dimension.
Demo-grade securityThere's no authentication (the user is mocked client-side), CORS allows * with credentials, and there's no rate limiting. Fine for local use only.
