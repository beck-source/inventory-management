Factory Inventory Management System

A workshop demo: Vue 3 single-page app talking to a single-file FastAPI service, backed entirely by in-memory data loaded from JSON files. There is no database.

System architecture

Three tiers running locally. The browser is the only client; the API holds all state in process memory.

Data flow

What happens when a user changes a filter on the Dashboard.

  1. User changes a filterFilterBar.vue → useFilters.js (period, location, category, status) State is a module-level singleton, so every view and the FilterBar see the same values.
  2. View reloads its dataviews/*.vue, via watch on the filters getCurrentFilters() maps the filter state to query params (period becomes month, location becomes warehouse).
  3. API client builds the requestclient/src/api.js Params equal to 'all' are dropped; axios issues GET /api/... to port 8001.
  4. FastAPI routes and filtersserver/main.py Endpoint calls apply_filters and filter_by_month, which are list comprehensions over the in-memory lists.
  5. Response is validatedPydantic response_model If a JSON file's shape drifts from its model, the response fails validation instead of returning bad data.
  6. View derives what it displaysVue computed properties Raw responses are stored in refs (e.g. allOrders, inventoryItems); KPIs, tables and SVG charts are computed from them.

Known gaps and caveats

Places where the client and server disagree, or behavior that is easy to assume incorrectly.

Missing Unimplemented endpoints

  • api.js calls /api/tasks (GET, POST, PATCH, DELETE) and /api/purchase-orders (POST, GET by backlog id).
  • main.py implements none of them. It defines the purchase-order models and only reads purchase_orders.json to compute has_purchase_order.
  • The Tasks modal and any purchase-order creation will fail against the current backend.

Unrouted Backlog view

  • views/Backlog.vue exists but has no route in client/src/main.js, so it is unreachable.
  • Backlog data still reaches the Dashboard through /api/backlog.

Coupling Hardcoded URLs

  • The API base URL is hardcoded in api.js and again in Reports.vue.
  • Moving the backend off port 8001 requires editing both.

Demo only Security posture

  • No authentication; useAuth.js is mock state on the client.
  • CORS allows all origins; no rate limiting.
  • Not suitable for anything beyond local development.
