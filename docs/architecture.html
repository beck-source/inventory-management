Architecture Overview

Factory Inventory Management System

A full-stack demo application: a Vue 3 single-page app talks to a FastAPI backend that serves factory inventory, orders, demand-forecast, and spending data from JSON files held entirely in memory — there is no database.

Vue 3.4 Vite 5.x · port 3000 Vue Router 4.3 Axios 1.6 FastAPI 0.110+ · port 8001 Pydantic v2 Python ≥ 3.11 · uv Pytest 40 backend tests

System Architecture

Three tiers: the browser SPA, the API server, and flat-file data loaded at startup. The frontend calls the backend cross-origin (no Vite proxy), which the backend compensates for with wide-open CORS.

Data Flow — filter change to re-render

Four global filters (Time Period, Warehouse, Category, Order Status) drive every view through the same pipeline:

User changes a filter in FilterBar.vue

v-model writes to singleton refs in composables/useFilters.js — shared module-scope state acting as a de facto global store.

Views react via watch

Each view watches the four refs and re-runs its loadData() when any of them change.

api.js builds the request

getCurrentFilters() maps UI state to query params (selectedLocation → warehouse, selectedPeriod → month); values of 'all' are skipped.

FastAPI filters in memory

apply_filters() and filter_by_month() run list comprehensions over the module-level data; responses are validated against Pydantic models via response_model.

Vue re-renders

Raw results land in refs (allOrders, inventoryItems); tables and custom SVG charts are derived in computed() properties.

Notable Characteristics & Gotchas

No persistence layer

Data is loaded once at import; restarting the server resets everything. All filtering is Python list comprehensions.

Frontend/backend API drift

api.js defines tasks and purchase-order calls (getTasks, createPurchaseOrder, …) that have no routes in main.py — they 404. Server-side scaffolding exists (models + empty purchase_orders.json).

Orphaned view

views/Backlog.vue is not registered in the router or nav; backlog data surfaces through a Dashboard modal instead.

Hardcoded API base URL

No Vite proxy — http://localhost:8001/api is hardcoded in api.js and again in Reports.vue; wildcard CORS makes it work.

State without a store library

Global filter state is module-scope refs in a composable — simple, but shared mutable state all views depend on.

Everything hand-rolled

Custom SVG charts (no chart lib), hand-built EN/JA i18n, mock auth. Quarter logic is hardcoded to 2025.
