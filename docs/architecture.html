System Overview

Full-stack inventory management application with Vue 3 frontend, Python FastAPI backend, and in-memory JSON data storage. Supports multi-language (EN/JP), real-time filtering, and comprehensive analytics.

  • FastAPI Framework
  • Pydantic Models

  • Filter Logic
  • Mock Data Loader

Data Layer

  • In-Memory Storage
  • No Database

Data Flow Architecture

1
User Interaction User selects filters in FilterBar component (Time Period, Warehouse, Category, Status)
2
Global State Update useFilters() composable updates reactive refs shared across all components
3
Component Reaction Watchers detect filter changes and trigger API calls via api.js client
4
HTTP Request Axios sends GET request to FastAPI backend with URLSearchParams filters
5
Backend Processing FastAPI applies filters to JSON data, validates with Pydantic, returns filtered results
6
Component Update Component stores data in reactive ref, computed properties transform for display
7
Template Rendering Vue reactivity system re-renders template with v-for bindings and updated data

Key Features

Multi-Language Support

Full UI translation for English and Japanese, including product names, customer names, and warehouse locations. Currency auto-converts between USD and JPY.

Global Filter System

4 synchronized filters (Time Period, Warehouse, Category, Status) apply across all views via shared composable state.

Reactive State Management

No external state library. Uses Vue 3 Composition API with composables for shared state and computed properties for derived data.

Custom SVG Charts

Responsive donut and bar charts built with native SVG and CSS, no external charting libraries required.

Pydantic Validation

All API responses validated with Pydantic models ensuring type safety and consistent data structure.

Purchase Order Workflow

Backlog items can be linked to purchase orders, enabling tracking of procurement relationships and supplier management.
