Factory Inventory Management System — Architecture

Full-stack demo application: Vue 3 single-page frontend, a Python FastAPI backend, and in-memory mock data loaded from JSON files (no database). Built for GitHub-integrated workflows.

Vue 3 · Composition API Vite FastAPI Pydantic No Database

Tech Stack

Frontend

  • Vue 3.4 (Composition API)
  • Vite 5 dev server / bundler
  • vue-router 4 (6 routes)
  • axios for HTTP calls
  • Runs on localhost:3000

Backend

  • Python FastAPI
  • Pydantic v2 models for validation
  • Uvicorn ASGI server
  • Auto docs at /docs
  • Runs on localhost:8001

Data

  • Static JSON files in server/data/
  • Loaded into memory at startup
  • Filtered in-process (no query engine)
  • Resets on server restart

Request / Data Flow

  1. User adjusts one of the 4 global filters (Time Period, Warehouse, Category, Order Status) in FilterBar.vue, backed by the useFilters.js composable.
    Filter state lives in shared refs so every view reacts to the same selection.
  2. The active view (e.g. Dashboard.vue, Inventory.vue) calls a function in client/src/api.js, passing the current filters as query params.
    API calls are centralized — components never call axios directly.
  3. FastAPI receives the request in server/main.py and applies matching filters (warehouse, category, status, month) against the in-memory dataset.
    Filters are skipped when the value is "all".
  4. Results are validated and shaped by Pydantic response models before being returned as JSON.
    Guarantees the frontend always receives a consistent schema.
  5. The view stores the raw response in a ref (e.g. allOrders, inventoryItems); computed properties derive totals, chart data, and grouped views from it.
    Raw data in refs, derived data in computed — recalculates only when dependencies change.

Project Layout

client/src/

  • views/*.vue — page-level components (6 routes)
  • components/*.vue — modals, filter bar, profile menu
  • composables/ — useFilters, useAuth, useI18n
  • api.js — single axios client, all HTTP calls
  • locales/ — en / ja translation strings

server/

  • main.py — FastAPI app, routes, Pydantic models
  • mock_data.py — loads + filters JSON data
  • generate_data.py — regenerates mock datasets
  • data/*.json — inventory, orders, spending, demand, backlog, transactions, purchase orders
