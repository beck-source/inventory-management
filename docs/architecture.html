Factory Inventory Management System

A demo dashboard for inventory, orders, demand, spending and reports. A Vue 3 single-page app calls a FastAPI service, which serves sample data from JSON files held in memory. There is no database and no authentication.

Tech stack

Frontend

Vue 3.4Composition APIVue Router 4AxiosVite 8
  • The UI uses an "industrial precision" design: Archivo, IBM Plex Sans and IBM Plex Mono from Google Fonts, a slate palette with one amber accent, all defined as CSS custom properties.

Data flow: applying a filter

FilterBarThe user picks a period, warehouse, category or status.
useFiltersShared refs update, and getCurrentFilters() maps the period to month.
api.jsBuilds query params and leaves out any value set to "all".
FastAPIapply_filters and then filter_by_month run over the in-memory lists.
PydanticValidates the response and serializes it to JSON.
ViewThe raw result goes into a ref. Totals and charts are computed properties.

Quarter filters such as Q1-2025 expand to a list of months through QUARTER_MAP and are matched against each order's order_date. Inventory has no time dimension, so the month filter never applies to it.

Things to know

Two kinds of task coexist. The profile's sample tasks (numeric ids) come from useAuth.js and live only in the browser. Tasks added in the UI go to /api/tasks and get string ids like TASK-1, so App.vue can tell them apart.
Most changes to data are not saved. The data lives in memory, so tasks and purchase orders are lost when the server restarts. Only restocking orders are written back, to submitted_orders.json.
The API URL is hard-coded. api.js points at http://localhost:8001/api, and the Vite config sets no proxy.
