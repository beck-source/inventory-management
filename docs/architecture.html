Factory Inventory Management System

Architecture overview. A full-stack demo app: a Vue 3 single-page app talks to a Python FastAPI service over REST. The service holds all data in memory, loaded from JSON files at startup. There is no database.

System Architecture

The app has three tiers. All of them run locally. The browser calls the API directly (CORS allows all origins). Vite does not proxy requests.

Data Flow

This is the request lifecycle when a user changes a global filter, such as selecting the "San Francisco" warehouse on the Dashboard.

1

User picks a filter

FilterBar.vue writes to a shared ref, e.g. selectedLocation

2

View reacts

A watch in the view calls getCurrentFilters(). The period becomes month

3

api.js builds request

Filters become query params, and any filter set to "all" is dropped. axios sends the GET

4

FastAPI filters

apply_filters and then filter_by_month run over the in-memory lists

5

Validate and return

The Pydantic response_model validates and serializes the JSON response

6

Render

Raw data goes into refs, and computed properties derive KPIs, charts, and tables

# Example: Dashboard with Q3 + San Francisco + Electronics
GET /api/dashboard/summary?warehouse=San%20Francisco&category=electronics&month=Q3-2025

# server/main.py
filtered_inventory = apply_filters(inventory_items, warehouse, category)          # inventory has no time dimension
filtered_orders    = filter_by_month(apply_filters(orders, warehouse, category, status), month)
return { total_inventory_value, low_stock_items, pending_orders, total_backlog_items, total_orders_value }

Filter state

Four refs at module scope in useFilters.js (Period, Location, Category, Status). Every component that calls useFilters() shares the same state, so no store is needed.

Time filtering

Matches on a substring of order_date. Quarters such as Q3-2025 expand to three months through QUARTER_MAP. Applies only to orders, not to inventory.

Localization

useI18n looks up dotted keys in locales/en.js and locales/ja.js. The locale also sets the currency (USD or JPY), which utils/currency.js formats.

Observations

I found these gaps while reading the code. They help explain how the system behaves today.

Task endpoints are missing App.vue calls api.getTasks() and api.createTask(), but main.py has no /api/tasks route. These requests return 404.
Purchase order endpoints are missing api.js defines createPurchaseOrder and getPurchaseOrderByBacklogItem, and main.py defines the PurchaseOrder and CreatePurchaseOrderRequest models, but no routes use them.
Backlog.vue is not routed views/Backlog.vue exists but is not registered in main.js. Backlog data appears only on the Dashboard.
Inconsistent API access Reports.vue imports axios and hard-codes the URL instead of going through api.js.
Data does not persist All state lives in Python module globals. Any write would be lost when the server restarts.
